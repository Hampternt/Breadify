## Goal

One binary per platform, licences in order, and an honest account of what
still has to be checked by a person.

**Observable when done:** a tagged push produces a Linux binary and a Windows
`.exe`, and someone who has never seen the repo can read the README and print
a day's lists.

**Deviations:**

- **The Windows binary is built in CI, not here.** This machine has no mingw
  toolchain and no `cargo-xwin`, so nothing Windows-shaped can be verified
  locally. The workflow builds it on a Windows runner; the first tagged
  release is the first time anyone will have run it, and that is worth
  knowing rather than glossing.
- **The window keeps its native decorations** (from pack 4). Borderless with
  hand-rolled resize regions on Wayland is a pack of its own.
- **Density is not built** (from pack 5), and neither is an in-app printer
  dialog (D18).
**Code review:** one pass at high effort over a pack that is mostly
configuration. Nothing found worth reporting: the release profile, the
workflow, the README and the licence output have no logic to get wrong, and
the one behavioural change — `--help` and `licences` as commands — was run.

**Pack gate:** `./scripts/verify.sh` — fmt, clippy `-D warnings`, build, 93
tests, all green. The release binary was then copied into an empty directory
with only the export beside it and asked to print the day: 26 sheets, 2.1 MB,
no complaint.

## What the container came to

Seven packs, all merged. The app reads an export, checks it, lets the user
change the few things that are theirs to change, and prints 26 A4 sheets for a
day of 352 order lines. Every figure in the docs was recomputed from the file
rather than quoted, and six that had survived a design pass turned out to be
wrong.
