## Goal

One binary per platform, licences in order, and an honest account of what
still has to be checked by a person.

**Observable when done:** a tagged push produces a Linux binary and a Windows
`.exe`, and someone who has never seen the repo can read the README and print
a day's lists.

**Deviations:**

- **The Windows binary is built in CI, not here.** This machine has no mingw
  toolchain and no `cargo-xwin`, so nothing Windows-shaped can be compiled
  locally. Run
  [33048429401](https://github.com/Hampternt/Breadify/actions/runs/33048429401)
  built it on a Windows runner and attached `breadify.exe` — so it compiles,
  and the Linux-shaped `wayland`/`x11` eframe features are inert there as
  expected. Nobody has **run** it: the window, the file dialog and handing a
  PDF to the system handler are all unexercised on Windows.
- **The window keeps its native decorations** (from pack 4). Borderless with
  hand-rolled resize regions on Wayland is a pack of its own.
- **Density is not built** (from pack 5), and neither is an in-app printer
  dialog (D18).
**Code review:** one pass at high effort over a pack that is mostly
configuration. Nothing found worth reporting: the release profile, the
workflow, the README and the licence output have no logic to get wrong, and
the one behavioural change — `--help` and `licences` as commands — was run.

**Pack gate:** `./scripts/verify.sh` — fmt, clippy `-D warnings`, build, and **87 tests**
across 15 files, all green — counted, not estimated. The release binary was then copied into an empty directory
with only the export beside it and asked to print the day: 26 sheets, 2.1 MB,
no complaint.

## Two corrections to this pack's own record

- **The test counts in packs 4 to 6 were incremented by estimate rather than
  summed**, and the commit messages carry them: 85, 89 and 93 against a real
  87 today. The manifests no longer quote a number they did not count. Said
  plainly because this repo's own risk list ends with *assume any hand-written
  figure is unverified*, and that has to include its own.
- **CI failed on its first run** — a clippy lint that exists on the runner's
  toolchain and not on this machine's 1.96. The gate is only as strict as the
  toolchain running it; the workflow catching something the local gate could
  not is the workflow doing its job.

change the few things that are theirs to change, and prints 26 A4 sheets for a
